# Security policy

## Scope

OpenAPI Security Lint is a local specification linter. It does not send requests
to the API described by a specification, and its findings are review signals
rather than confirmed runtime vulnerabilities.

## Reporting a vulnerability

Please report security issues privately to the repository maintainers through
GitHub's **Report a vulnerability** feature. Include the affected version, a
description of the issue, and steps to reproduce it. Do not include production
credentials or sensitive API specifications in a public issue.

Reports will be acknowledged and triaged as soon as practical. A fix and public
advisory will be coordinated with the reporter when appropriate.
