# Code of Conduct

We want participation in openapi-sec-lint to be respectful, constructive, and focused on improving the project. Contributors agree to:

- Be considerate and assume good intent.
- Give and receive feedback with respect.
- Focus criticism on ideas and code, not people.
- Respect privacy and avoid posting credentials, customer data, or private API specifications.

Harassment, discrimination, personal attacks, and deliberate disruption are not acceptable. Project maintainers may edit or remove contributions and restrict participation when needed to protect the community.

This code applies in project spaces, including issues, pull requests, discussions, and project-related events. Report conduct concerns privately to the repository owner through the contact information on their GitHub profile. Do not post personal or sensitive details in a public issue.
